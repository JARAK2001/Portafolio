# Andrés Cifuentes · Portafolio Interactivo 3D 🌳✨

> *"Ideas que echan raíces"*

Portafolio web personal e interactivo inspirado en la metáfora del **Árbol de las Estaciones** (Guayacán 3D). Diseñado y construido con **React 19**, **Three.js** y **Vite**, fusionando narrativa botánica con ingeniería de software, arquitectura de sistemas e inteligencia artificial aplicada.

---

## 🌟 Características

- **Escena 3D Interactiva con Three.js:**
  - Modelo 3D de un guayacán en flor con texturas PBR horneadas en calidad 4K.
  - Viaje de cámara suavemente sincronizado con el scroll a lo largo de las distintas paradas del árbol.
  - Terreno procedural con raíces dinámicas, iluminación nocturna, partículas y pétalos flotantes.
- **Narrativa Botánica y Estructura:**
  - **Raíces:** Fundamentos y principios ("El dominio manda", "La IA propone, el sistema valida").
  - **Tronco:** Evolución técnica y trayectoria profesional.
  - **Ramas:** Tecnologías y stack técnico con evidencia directa en proyectos.
  - **Flores:** 16 proyectos clasificados por niveles de impacto con fichas técnicas detalladas.
  - **Semillas:** Futuro, visión y canales de contacto.
- **Accesibilidad y Rendimiento:**
  - Modo de movimiento reducido (*Calm Mode* / `prefers-reduced-motion`).
  - Fallback automático para dispositivos sin soporte WebGL.
  - Cálculo dinámico de framerate y optimización de render loops.

---

## 🛠️ Stack Tecnológico

- **Frontend:** React 19, JavaScript (ESM), CSS moderno.
- **Gráficos 3D:** Three.js, GLTFLoader, OrbitControls.
- **Bundler & Tooling:** Vite 8, Oxlint.
- **Despliegue:** Vercel.

## 🚀 Inicio Rápido

### Prerrequisitos
- Node.js >= 18
- npm >= 9

### Instalación
```bash
# Clonar el repositorio
git clone https://github.com/JARAK2001/Portafolio.git

# Entrar al directorio
cd Portafolio

# Instalar dependencias
npm install
```

### Ejecutar en desarrollo
```bash
npm run dev
```

### Compilar para producción
```bash
npm run build
```
